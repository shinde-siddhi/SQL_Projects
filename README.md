# SQL Projects Portfolio

A collection of SQL projects demonstrating database creation, data querying, and data analysis using MySQL.

## 📌 Projects

### 1. Student Performance Analysis Using SQL

**Folder:** `Student_Performance_Analysis/`

**Project Overview:**  
This project analyzes student academic performance using MySQL. It evaluates marks, calculates percentages, identifies toppers, and compares subject-wise results.

**Key Analysis:**
- Calculate total marks and percentages.
- Identify the top three students.
- Find subject-wise toppers.
- Calculate average, highest, and lowest marks.
- Analyze subject-wise pass percentages.
- Identify students who failed in any subject.
- Compare results by gender and section.
- Assign grades and rank students.

**SQL Concepts Used:**
- SELECT, WHERE, ORDER BY
- Aggregate Functions: SUM(), AVG(), COUNT(), MIN(), MAX()
- GROUP BY and HAVING
- JOINs
- Subqueries
- CASE Statements
- Window Functions: RANK()

**SQL File:** `student_performance_analysis.sql`


### 2. Sales Performance Analysis Using SQL


**Project Overview:**  
This project analyzes retail business data using SQL. It explores customers, products, orders, order items, and payments to understand sales performance.

**Key Analysis:**
- Analyze customer and order details.
- Calculate sales totals using aggregate functions.
- Analyze product-wise and monthly sales.
- Combine multiple tables using JOINs.
- Explore retail sales trends.

**SQL Concepts Used:**
- SELECT, WHERE, ORDER BY
- Aggregate Functions: SUM(), AVG(), COUNT(), MIN(), MAX()
- GROUP BY and HAVING
- JOINs
- CASE Statements
- Subqueries
- Date-based analysis

**SQL File:** `sales_performance_analysis.sql`

## ▶️ How to Run

1. Install MySQL Server and open MySQL Workbench.
2. Download or clone this repository.
3. Open the SQL file for the project you want to run.
4. Execute the script to create the database, tables, and sample data.
5. Run the analysis queries and review the results.
